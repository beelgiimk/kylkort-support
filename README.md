# Kylkort Support

Officiell supportsida, integritetspolicy och användarvillkor för mobilappen
Kylkort.

Webbplatsen är statisk och avsedd att publiceras med GitHub Pages.

## Publicering

1. Öppna repository-inställningarna på GitHub.
2. Gå till **Pages**.
3. Välj **Deploy from a branch**.
4. Välj `main` och `/ (root)`.

Supportadress läggs till före App Store-lanseringen.
